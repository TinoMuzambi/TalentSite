# Talent Muzambi

A fast, accessible professional profile for Dr Talent Muzambi, covering selected experience in business analysis, enterprise development, strategy, finance, and advisory work.

**Live site:** [talent-muzambi.vercel.app](https://talent-muzambi.vercel.app)

## Develop

The site uses semantic HTML and dependency-free CSS. Serve the repository with any static server:

```bash
python -m http.server 8000
```

## Test

```bash
python -m unittest discover -s tests
```

The test suite checks document structure, accessibility essentials, internal asset references, and the absence of third-party runtime dependencies.
